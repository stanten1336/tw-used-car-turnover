# 台灣中古車上架比與下架速度

公開儀表板，用 8891 中古車在架數與公路局小客車掛牌數，估算各品牌的**上架比**與**下架速度**。

這兩個數字都是代理指標，**不是官方週轉率**。公路局只公布各品牌掛牌數量，沒有公布各品牌過戶數，而週轉率的分子就是過戶數。

- 上架比＝當日 8891 在架台數 ÷ 公路局最新月份「小客車」登記數
- 下架暫定為銷售（以下架計）。需累積數週每日快照後，30 日銷售、售出率與已售平均在架天數才比較準

資料來源：

- [8891 中古車公開搜尋](https://auto.8891.com.tw/search)
- [交通部公路局統計查詢網：機動車輛登記數－按廠牌分（汽車）](https://stat.thb.gov.tw/hb01/webMain.aspx?sys=100&funid=1110003)

本站只放加總後的統計 JSON，不含逐車名單。

熱賣車型＝該車系在最近最多 30 日快照比較中，下架（銷售以下架計）次數最多者；平均售價是這些下架物件最後一次在架價格的平均（排除面議與不合理價格），並同時列出該車系目前在架均價與台數。樣本偏少時會註明，並另列目前在架最多的車系當參考。
